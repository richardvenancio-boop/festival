## Briefing

### Público

O Neon Pulse Festival é voltado principalmente para jovens e adultos
que gostam de música eletrônica, tecnologia, experiências visuais e
eventos modernos.

### Clima

- Urbano
- Futurista
- Energético

### Paleta de cores

- **#0B0B0F** — usado como fundo principal.
- **#111118** — usado nas seções principais.
- **#00F5D4** — usado nos destaques, botões e detalhes.
- **#F5F5F5** — usado nos textos principais.
- **#33333D** — usado nas bordas e divisões.

### Fontes

**Orbitron:** usada nos títulos porque possui uma aparência
futurista e tecnológica.

**Roboto:** usada nos textos porque é simples e facilita a leitura.

## Os 4 prompts que mais fizeram diferença

1. Crie uma página inicial para um festival de música eletrônica
   chamado Neon Pulse, utilizando fundo escuro, detalhes em verde
   neon e tipografia futurista.

2. Organize o menu do site utilizando display flex e deixe o nome
   do festival no lado esquerdo e os links no lado direito.

3. Crie uma página de line-up com oito artistas, mostrando nome,
   dia, horário e palco de cada apresentação.

4. Deixe o site responsivo para que o menu, os artistas e os ingressos
   se adaptem a telas menores.
